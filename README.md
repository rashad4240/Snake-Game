# 🐍 Snake Game

A classic Snake Game developed using **Python and Turtle Graphics**. This project demonstrates fundamental Python programming concepts along with Object-Oriented Programming, file handling, keyboard controls, collision detection, and score management.

## 🎮 Features

* 🐍 Classic Snake gameplay
* ⌨️ Keyboard-based movement controls
* 🍎 Food generation and score tracking
* 💥 Wall and self-collision detection
* 🏆 High-score tracking
* 💾 High score stored using **File Handling**
* 🔄 Continuous gameplay with increasing difficulty

## 🛠️ Technologies & Concepts

* **Python**
* **Turtle Graphics**
* **Object-Oriented Programming (OOP)**
* **File Handling**
* **Classes & Objects**
* **Loops & Conditional Statements**
* **Event Handling**
* **Collision Detection**

## 🚀 How to Run

1. Clone this repository.
2. Open the project in **VS Code or PyCharm**.
3. Make sure Python is installed.
4. Run the main Python file:

```bash
python main.py
```

5. Use the **Arrow Keys** to control the snake.
